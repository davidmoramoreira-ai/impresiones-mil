# 🖨️ Impresiones Mil

Sitio web responsivo e interactivo diseñado para la presentación de servicios de impresión, diseño y papelería.

---

### 🚀 Enlace en Vivo
Puedes ver la página funcionando en producción aquí: [Ver Demostración en Netlify](https://impresiones-mil.netlify.app)

---

### 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Despliegue:** Netlify

---

### 📂 Estructura del Proyecto
* `index.html` — Estructura principal de la página web.
* `estilo.css` — Estilos personalizados, diseño responsivo y paleta de colores.
* `main.js` — Funcionalidades interactivas de la interfaz.
